# 项目执行约定

目标是小步跑通、发现问题、积累经验。当前只做教学原型，优先维护已经能工作的完整流程。

- 开始前阅读 README 和与本次改动相关的文档，不例行通读所有文件。
- 当前用户已确认：先做肿瘤指南、药物、临床试验检索，医保核查后续再做。
- 真实资料与教学资料必须有清晰边界。不能将教学样例改名为真实指南、药物适应症或招募试验。
- 空白信息保持未知。词表、模型、向量相似度都不能自动证明临床适用性或试验入组资格。
- 新接模型或外部数据服务时，先明确发送的数据、资料权利和院内边界；不自行上传患者资料。
- 运行数据保存到本项目 var 目录。保留已有问题记录，不把病例、凭据或真实病历加入代码库。
- 用 uv 管理 Python；数据不足以说明需要新组件时，不增加向量库、队列或微服务。
- 完成改动后运行对应的最小有效检查；实际遇到的新问题写入 docs/lessons.md，注明现象、处理和下一步。
- 修改用户可见流程时，用真实浏览器验证至少一次关键路径。后续授权或真实数据接入不从本次演示授权推导。
