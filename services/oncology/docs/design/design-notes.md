# 界面设计依据

界面参考图为 workbench-concept.png，由内置 Image Gen 生成，提示要求一个中文肿瘤检索工作台完整主屏，保留病例录入、字段确认、三类检索与问题记录流程；白底、浅灰侧栏、深青色主按钮，原生文字与控件，不使用医疗装饰图或虚构统计。

完整生成提示保存在 [concept-prompt.txt](concept-prompt.txt)。实际返回的参考图尺寸为 1505 × 1045，浏览器对照使用相同尺寸。

采用约 244 px 侧栏、两列工作区、左侧病例表单、右侧资料列表。颜色：背景 #ffffff、侧栏 #edf2f5、主色 #16645d、文字 #20343b、辅助文字 #708594、边框 #d6e1e6。系统中文无衬线字体，正文 14～15 px，标题 24～34 px，控件 5 px 圆角。

主要文案沿用参考图：肿瘤工作台、病例与资料检索、从一段病例，找到有出处的资料、工作台、资料目录、问题与经验、病例信息、使用示例、提取字段、查询资料、检索结果、查看依据、记录问题。

功能所需的明确差异：默认展示空状态，完成真实查询后才显示结果；补充“请勿输入真实患者信息”；增加有限词表说明、待核对提示、冲突条目和问题记录表单。参考图中的已填入病例、已勾选和已有结果不是默认的虚假状态。

手机端改为顶部导航和上下单列；所有数据文字与按钮均由 HTML 和 JavaScript 渲染，参考 PNG 不充当界面。
