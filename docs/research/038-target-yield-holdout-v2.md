## 已完成的目标验证

- 在目标生产库中只读核对阿来替尼和黑色素瘤两个 ID：均存在，名称与冻结字典一致。按精确有序融合、药物、主癌种和同一来源做有限查询，现有同键数和同源数均为 0；不能据此排除其他写法或语义重复。
- 使用与正在运行目标服务相同的镜像，在无网络、只读挂载、全新 SQLite 内存库中调用真实目标 serializer：这条未分级、未赋值药效、未启用知识可保存并在管理搜索中找到；不存在的药物／癌种 ID 及精确重复均被拒绝。上述 ID 在隔离库中作为事先核对过的夹具，不是对生产数据的写入。
- 未启用时不产生样本匹配。在隔离库中模拟审核并启用后，合成 EML4→ALK 和黑色素瘤命中 1 次；反向 ALK→EML4、不同伙伴 KIF5B→ALK、错误癌种和缺失伙伴均未命中。尚未测试真实患者或完整临床消费路径。
- 目标库位点列表没有为该精确融合提供预置条目，详情显示未解析，但目标代码能从完整的合成融合事件生成精确事实并命中；不得把它扩大成 ALK 任意融合。
