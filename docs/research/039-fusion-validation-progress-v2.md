# 039 · 五篇融合验证的补充记录

记录于 2026-11-13（UTC）。本记录补充 [五篇验证阶段结果](039-fusion-validation-in-progress.md)，保留原始样本和原文参考，不将开发结果当作独立准确率。

## 目标药物身份碰撞

当前使用的目标字典快照有 501 个药物条目，42 个规范化名称各命中多个目标 ID；752 个癌种条目中有 80 个名称碰撞。它们只是检索名称碰撞，不能据此断言所有条目都是重复实体，癌种同名还可能涉及层级或范围差异。

38 个重复的英文药物名称中，23 个能按完整英文名精确对应唯一的本地 RxNorm 成分，15 个没有精确成分名；后者包括组合方案等。标准成分可作为后续判断的依据，但不能单凭同名合并目标 ID。

例如 lorlatinib 在本地对应 `RXNORM:2103164`；目标快照中“劳拉替尼”和“洛拉替尼”有不同 ID，证据中心当前仅引用后者 4 次，旧药物知识分别引用前者 5 次、后者 26 次。两者历史引用均存在，当前映射保留歧义，既不自动新建同名药物，也不把两个 ID 填成联合用药。上述目标数据通过有界只读查询核对，未读取患者数据。

可复用的解决方向是：先以标准成分形成一个本地药物实体，保留多个目标身份及来源；对确有充分证据的目标消费路径确定稳定输出 ID，并在查重时保留其他已知 ID。当前尚未验证完整目标消费和跨 ID 语义查重，因此没有在后台自动选择。

## 模型加载与状态

整模型预热期间，已读取的权重页被系统回收，导致无法稳定满足预热条件；已停止该方式并保存观测。改用只对本次试验启用的按权重分段读取，读取节奏为 8 MiB/s，并根据共享磁盘、内存和 GPU 状态等待或暂停；这不是对服务器所有磁盘 I/O 的总限速。真实 Transformers 小模型测试中，加载前后权重及输出一致；启动前会核对限速器已安装，原分类和筛选脚本指纹保持不变。

记录时，3 篇新增文献的 4B 分类已复用，9B 筛选仍在加载模型，尚无这 3 篇的抽取结果。处理完成后会自动生成候选结构对照；Astra 原文语义核验、独立知识去重和是否接入后台仍需完成。另一篇诊断病例的隔离预览和目标合成匹配已在原阶段记录中说明，尚未写入 tumor_api。

原常驻知识任务仍按既定夜间时段运行；新增全文发现的锁恢复修复已通过模拟及临时队列测试，实际夜间运行效果尚待观察。
