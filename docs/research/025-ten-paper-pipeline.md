# 025 · 十篇文献批量知识提取

目标是给定文献清单，得到可回查的 biomed 知识、tumor_api 离线结构包和逐条缺口。沿用 4B 文献三分类、9B 段落筛选／实体抽取及 Bonsai 关系抽取；不训练、不改 tumor_api、不导入生产。质量核验独立于知识提取和保存。

## 本轮必要改动

- 输入准备接受冻结快照和任意 PMID 清单，取消固定五篇约束；默认处理全部入选段落。
- 文章缺全文、零入选、模型输出失败、超上下文分别保存状态；一个片段失败不阻止其余片段处理。进程中断可复用已有断点。
- 已确认的本地实体规则与冻结目标字典参与目标适配，不再依靠固定三十条样本的映射表。
- 区分目标字段合法、源文条件支持、旧快照覆盖和真实样本匹配。目标 direct 创建接口允许新的具体变异键；旧快照未覆盖本身不等于结构不合法。新键须有原文与提取条件支持，基因来自本地标准，禁止把蛋白表达、基因家族或泛突变造为具体 DNA 事件。新键的快照状态为 `not_covered`，真实样本匹配仍为 `unverified`，不标生产提交就绪。适配合同版本为 `biomed.target-contract-assessment.v4`，旧研究产物保留。

## 固定样本与输入边界

十篇主批来自已有合法 JATS 全文，覆盖尿路上皮癌、结直肠癌、胶质瘤、黑色素瘤治疗安全性、乳腺癌、宫颈癌、肺鳞癌、肛管癌、前列腺癌及鼻咽癌，共 432 个已解析段落。这是按研究内容选取的开发批次，不是随机留出集。

主批选样和来源冻结于 `var/experiments/ten-paper-sources-20261102/`，模型与交付于 `var/experiments/ten-paper-closure-20261102/`，均经兼容入口保存在约定的 appdata 目录。当前输入支持已有 JATS 正文段落；不声称覆盖扫描 PDF、正文表格或补充附件。

4B对标题摘要判定9篇实体瘤、1篇非肿瘤。后者为PMID 42831218（免疫治疗相关糖尿病／甲状腺毒症），正文明确有黑色素瘤患者；将全部28个已解析段落输入同一4B（5,940 tokens、未截断）后仍判非肿瘤。原结果均保留，本轮没有把它强改为实体瘤或冒充补判成功。它提示“主要研究疾病”与“肿瘤治疗相关知识”的分类范围边界，不能据此断言该文与肿瘤知识无关。当前9篇进入后续提取，第10篇作为待复核的分类边界记录，尚未评估全批漏筛率。

本地全文没有足够明确的精确变异—靶向药正例，因此另保存一篇目标适配对照：PMID 40445863（KRAS G12C、NSCLC、sotorasib 的真实世界单臂研究），不替换主批文献、不混入主批分母。复用本库 PubMed 原版本，仅按原限速取得一份 CC BY 4.0 JATS。来源与许可核验保存在 `var/experiments/target-positive-source-20261102/`。原文一处数字分母错误已标记，不能据此补造结果。

这篇对照实际抽出的主要是 ctDNA 动态与治疗结局关联；包括 body/p:16 的记录也选择了基线可检出／不可检出亚组比较，没有抽出总体人群的 ORR 31% 作为独立事实。因此它是目标表达边界的实测样本，不能称为适配成功正例，不能为了得到通过而删除 ctDNA 条件或改写结果。共25个片段记录，21条完成且结构合格，4条9B重复生成达到输出上限，明确保留失败；初版离线适配通过为0。这不等于21条知识均经语义核验正确。

另用 PMID 34096690（2021 年 sotorasib 单药治疗 KRAS p.G12C 非小细胞肺癌试验）验收明确分子条件的目标结构路径，限定前三个入选片段，不替换十篇主批。它是单独的历史对照，不改变近五年采集范围；NIH 作者稿的文本挖掘／合理使用声明不等于 CC 或商业再分发许可。实际原文件、许可和本地段落 ID 冻结于 `var/experiments/target-trial-source-20261102/`。

## 可重复入口

```bash
.venv/bin/python scripts/run_literature_batch.py \
  --root var/experiments/NEW_BATCH \
  --snapshot var/experiments/SOURCES/snapshot.json \
  --selection-file var/experiments/SOURCES/selection.json \
  --dictionary var/experiments/target-compatibility-20261101/target-dictionary.json \
  --registry var/experiments/REGISTRY/registry-snapshot.json
```

同一命令恢复相同输入；修改模型预算、来源或方法时使用新版本目录。`--import-to-local` 只向 biomed 追加候选和复用归一规则，不发布或导入目标。模型均复用 `/data/models`，不复制或下载权重。

仅做小范围验收时可显式传 `--per-document-limit 3`。上限绑定批次，余下片段以待处理清单保存；不传则处理全部入选片段。不能在同一冻结批次改动这个上限。

交付目录保留全部知识、全部适配预览、离线结构通过子集和未通过原因。`offline_ready` 只代表离线检查；`submit_ready` 始终为 false。登记入口为 `scripts/publish_literature_batch.py`，仅接受与冻结输入及真实入库回执一致的结果；可用 `--observations` 附加独立问题，不修改事实和质量状态。

最终映射的83项针对性测试、研究投影的独立观察测试及前端构建通过。真实浏览器验证了210条分页、按组号过滤、目标ID、两处独立问题、文章链接和原文定位；1440与390宽度无整页横向溢出，控制台无错误。Browser plugin未提供，使用现有Playwright。资料采集配置、全量采集状态和模型资源目录未改动。
