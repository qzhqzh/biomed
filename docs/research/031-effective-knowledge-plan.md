# 031 · 提高目标可用知识产出的优化方案

状态：**已完成小样本诊断与离线原型，尚未达到接入常驻流程的条件**。制定时间：2026-11-12（北京时间）。具体实验、结果和限制见 [032 · 知识利用率诊断与对照](032-effective-knowledge-diagnosis.md)。

## 目标与边界

主目标是：在保留真实来源和必要适用条件的前提下，增加能由 tumor_api **证据中心**表达的独立知识，并降低每条有效知识的处理成本。候选记录数、结构合格数和离线适配数分别报告，不以其中任何一个替代医学准确性或独立知识数。

现有66个完成批次保存4,999条候选，3条通过目标离线结构检查；其中1条已在历史研究出现，另外2条尚未独立医学核验。2,363条按现有规则列为待处理，1,223条初判目标范围不适用，1,410条有结构缺口；这些均为机器分流，不是人工金标准。相较11月9日16:21新增1,770条候选，但离线通过数没有增加。

目标范围沿用已冻结的证据中心合同和本地实体快照：每项结论需要目标支持的分子触发条件，包括 mutation、cnv、fusion。表达量、影像模型和普通治疗不能改写成基因变异；缺少触发条件的有效知识仍保存在 biomed，不计入证据中心产出。冻结合同并非对当前生产状态的实时确认，未来连接或导入前还需另行核对。

保持现有4B分类、9B段落/实体、Bonsai关系、本地规则和 PubTator 并行参考；不换模型、不微调，不把 Astra 加入每条提取路径。采集限速、全文预算、当前夜间窗口和已有数据保持原样；tumor_api 不连接、不改代码、不导入生产，biomed 可保存新版本结果。

## 根本问题与要验证的改法

目前提取结果已有疾病、治疗、条件、研究范围及证据等字段，但具体分子事件和实体关系仍可能留在自由文本中；目标治疗适配的一部分又依赖识别特定英文句式。即使文献已明确描述某一人群的变异与用药，不同写法或分段表达仍可能无法自动形成目标触发条件。独立的 `fusion` 词语分流误报是诊断问题，单独修词不会自动增加可用知识。现有日志和案例支持这些问题存在，但还不能据此断言它们解释了全部低产出。

拟采用兼容旧结果的**版本化事实字段**，将疾病及亚型、分子事件类型及具体事件、患者或实验对象、实际干预与比较、关系方向、必要条件、原始研究或引用来源，以及各项对应出处表达清楚；优先使用现有9B、Bonsai结果与本地实体规则，不另加全量模型环节。目标适配从有出处的实体、事件和关系出发，减少对某个完整英文句式的依赖。来源证据不足、实体身份不明或目标不能表达的必要条件仍保留未决状态；结构化字段是模型和脚本产生的候选，并不自动证明医学语义正确。

这是待小样本验证的结构性改法，不以单个例子补丁冒充通用解决；选文排序改善投入效率，断点恢复保证连续运行，二者本身不能保证产出正确知识。仅在旧输出不足以提供必要信息时定向重跑相应阶段，原数据及旧版本保留。

## 什么算本轮有效产出

以**独立事实**为单位：癌种、分子事件、干预或诊断/预后关系、方向和影响解释的必要条件需由原文支持，并有文章版本及具体段落出处。非必要的数字或修饰未进入目标字段，不自动算核心错误；原文和补充信息仍须可回查。相同事实来自不同文章时汇集出处，不因重复叙述增加事实数；不同人群、必要条件、比较方向或结论不得粗暴合并。记录与历史事实的去重依据及未确定项。

按以下层次分别展示，不能混算：

1. **现有目标实体的离线结构通过**：使用冻结的目标合同和已确认 ID，完整字段及触发条件通过本地检查。
2. **新实体自动补齐的隔离预览通过**：具体药物身份已确认但快照缺实体时，生成查重、自动新增和回填 ID 操作，在独立预览库执行并验证幂等；预览 ID 不是生产 ID。药物类别、联合方案或身份不明确的名称不伪造为单药，不设逐药人工审批。癌种、基因及事件等类型先核对各自目标合同和自动新增能力；未支持的依赖如实保留，不伪造 ID。
3. **质量抽样结果**：Astra 独立核对核心实体、关系方向、必要条件和文章/段落归属，标记支持、不支持或未确定。该参考不是专家金标准，质量抽查独立于自动提取、保存和 AI 通过发布机制。

目标合同无法执行某项影响含义的必要条件时，只写描述不等于目标能自动匹配；保留该条件及明确缺口，不能强行计入自动适配成功。

## 执行顺序

| 顺序 | 工作 | 实现方式与限制 |
| --- | --- | --- |
| 1 | 固定样本和基线 | 从已完成批次选30条候选：3条已有离线通过、9条待判断/映射、9条初判不适用、9条结构缺口；记录批次、PMID、组号、版本、文章/段落定位、原始输出及目标合同版本。上述类别是抽样入口，不当作真实标签。 |
| 2 | 检查真实损失 | 复用已有9B/Bonsai输出，针对候选和原文分开判断：未抽到、抽取结构不完整、目标可表达但映射未覆盖、目标确不能表达、来源归属或核心语义错误。Astra 仅用于固定样本参考：开发集先核读，留出集在方案固定后独立核读。 |
| 3 | 改善事实到目标的通用衔接 | 在已有结果上形成版本化的分子事件、实体角色、临床关系、必要条件和出处字段，映射时按这些带来源的关系处理，减少依赖固定英文句式；复核研究来源。不能补造融合伙伴、任意突变或删除必要条件。已有1–3条独立事实输出能力保留，仅对实际漏项调整。 |
| 4 | 调整处理顺序 | 用现有4B分类及规则给“明确分子事件＋临床关系”的全文提高队列优先级；其他实体瘤、疑难和低分文章保留回填。PubTator 仍是并行参考，不覆盖本地模型结果，不对全部元数据额外调用。 |
| 5 | 只修影响续跑的故障 | 显存不足先针对具体长输入设计可回查、保留上下文的分段/重试，不截断或静默丢失原文；冻结输出相同则复用，输入或实体快照不同则生成新版本，不覆盖历史结果。逐项隔离失败并保留断点。 |

定位模型或规则时，以现有案例作为开发对照：[影像 fusion 误命中](https://biomed.qzhqzh.com/knowledge/candidates/?q=E-42836110-0002)与[试验方案引用既往研究](https://biomed.qzhqzh.com/knowledge/candidates/?q=E-42838582-0012)。改善分流诊断本身不等于增加目标可用知识，必须单独统计实际产出变化。

## 有限对照与验收

- **30条样本一次完成**：按初始机器分流冻结3＋9＋9＋9；其中20条作为定位和修复样本（含3条既有通过对照），另10条按待映射3、初判不适用3、结构缺口4保留至改完后核验，两个集合的 PMID 不重叠。留出集各来自不同文献，参考核读直接基于原文、不依赖旧候选结果，以便发现原流程完全漏掉的知识；在修改方案期间不查看留出集原文或参考结论。两条已知问题放开发集。样本有意分层，不能外推全库准确率；若留出集原文没有可表达正例，不能据此证明召回改善。
- **同一批10篇全文验证闭环**：从上述保留集中选择10篇有原始全文和旧批次输出的不同文献，冻结输入和旧输出；新方案在独立版本目录运行。旧/新均给出癌种、分子事件、关系、条件、两层出处、目标载荷和缺口；尽量复用未受影响阶段，只对实际改变的环节重算。
- **产出**：分别报告旧/新目标离线通过数、隔离预览新增实体后通过数、去重后的独立事实候选数、其中相对历史的净新增数及新增来源数。复核去重与核心语义后才能将样本中的记录称作有效；不得把旧对照、不同片段或同义重复当新增。
- **质量与漏检**：固定样本逐条记录 Astra 参考的支持、不支持、未确定及理由；重点看错实体、错关系/方向、丢必要条件和错来源。非必要数字可以不进入目标字段，但已写出的数字不能编造或写错。检查保留集原文中可识别的目标事实是否被遗漏；仅能说明该小样本结果。参考与模型分歧保留，不用多数票直接定真伪。
- **区分各项收益**：先在同一批旧模型输出上单独比较映射和来源归属的修复；再在同一批全文比较处理顺序及确需重算的抽取。选文排序比较同一候选池中处理前5篇的产出，并保留其余文章以观察漏选；排序只影响先后，不删除低分文献。样本内无法证明收益的步骤不加入默认流程。
- **效率**：记录文章数、有效独立知识数、各阶段模型实际占用时长与峰值显存；另报墙钟耗时、模型加载、排队等待及复用的阶段。没有实际 GPU 时长时不把整批墙钟时间称作 GPU 小时；不得把仅重跑适配的耗时与全流程耗时直接比较。
- **接入条件**：同一批保留集至少新增1条经参考核对支持、具有两层出处且符合目标合同的独立事实；没有新增核心错误或把明确负例错误放行；经核读成立的既有通过对照不因技术变更退化。若保留集没有可表达正例，或改善只来自放宽条件、伪造 ID/事件，不宣布成功，也不扩大运行；报告具体原因。先对失败恢复和幂等做定向验证，再于批次边界接入。

验证结果和差异保存到 `/appdata/02_resource/apps/biomed/research/artifacts/` 的新版本目录；基线、候选、参考、出处、统计和运行耗时保留，旧批次及审核不覆盖。向用户展示具体新增知识与来源；通过验收的改动在批次边界接入常驻后台，不自动写入 tumor_api。
