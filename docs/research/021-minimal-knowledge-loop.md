# 021 · 最小知识闭环：保留独立实体步骤

本轮决定保留 **9B 独立实体抽取 + Bonsai 关系抽取**。删除独立实体步骤虽然减少模型调用，直接方案的核心关系错误、截断和参与实体问题更多；本轮不继续对直接方案调参。

只归档同 5 篇文献、15 个冻结片段组的实际消融。更多全文段落的工程验证独立记录，本页不把它计入样本量，也不宣称全文到知识的流程已经完成验证。

## 三项指标必须分开

1. **核心关系正确**：实际输出的癌种、具名治疗及组合/序贯、方向、必要分子限制和人体/细胞/动物范围是否正确。不要求复述全部统计量；已输出的数字若反转方向、错绑组别或扩张显著性，仍是核心错误。
2. **指定目标覆盖**：是否回答 ANCHOR 的目标。SUPPORT 中正确的额外事实可保留，但不能替代目标。
3. **参与实体及角色可用**：最终结构中的必要身份、类型和角色是否可用。库存里出现某实体，不表示它已经正确连接到关系；可定位的字符串也不证明关系正确。

三项交集单独显示，不能用其中一项替代整体通过。15 组始终计入分母，截断不剔除。参考由 Astra 根据原文建立，是模型参考，不是人工金标准；也不代表独立测试或临床准确率。

原始语义审核中，A 核心正确 15/15、目标覆盖 14/15；B 分别为 11/15、13/15。B 有 13 个完整 JSON 和 2 个截断。参与层初版 A 为 5/15、B 为 3/15；这些原始判断继续保留，后续组装分数不能覆盖它们。

最终组装采用 v3。A 从初版 5/15、v2 的 12/15 到最终 15/15 的变化保留完整审核链；B 参与层仍为 3/15。研究页面同时展示原始与最终结果，禁止将结构修复当成模型重新回答。

## 修复边界与仍需保留的错误

共用脚本修复类别保护、原文明确缩写、否定用药及既往暴露角色，并保留原始事实。药物类别不凭空变成具体成分；未用药不能因字面匹配而变成当前干预。v3 修正 A 中已被模型明确选中、却因缩写或动物模型描述不匹配而被脚本抹掉的癌种角色。B 的原词如果仅指定了错误段落编号，可在同一组原文中精确定位；脚本仍不能把猜测扩展名当作原文。这些修复没有增加模型调用，也没有修写原关系。

非目标分子类型问题改列诊断，是明确评价口径后的重新分类，不是工程修好了这些类型。S100 家族粒度、H3 K27-altered 状态等风险仍保留，不能由本次核心通过率推导出全部分子关系可直接生产使用。

值得保留的主要错例：

- **K04**：A 的额外事实本身正确，却未回答安全性目标；B 截断。这解释了为什么核心正确与目标覆盖要分开。
- **K07**：B 把当前治疗队列的趋势与独立数据集中的较差结局范围合并。实体齐全不能补救核心范围错误。
- **K13**：B 将部分模型、部分终点的显著性扩大到更广的比较；细胞模型也不能作为独立癌种节点。
- **组合及比较角色**：组合写成单药、具名成分未保留、背景治疗被接成实际对照，都会影响结构化检索；流畅的结论文本不能替代参与层核验。

研究页的 15 张逐组卡片保留文章、原始 ANCHOR/SUPPORT、两臂事实、实际参与实体及主要错误，可从文章追到段落。标准 ID 正确性和生产发布不在本轮评价范围内。
