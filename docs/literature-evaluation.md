本轮仅使用已保存的 1,000 篇元数据，采集继续暂停。评测不下载论文、不训练模型，不产生临床证据。数据目录为 `/data/06_project/biomed/var/library/evaluations/solid-tumor-eval-v1/`；含摘要的文件及核读记录均忽略提交。实施前数据库备份在 `/data/06_project/biomed/var/backups/literature-evaluation-20261015T170016Z/`，原有整合、采集备份及快照分支继续保留。

## 抽样与使用边界

2026-10-16（北京时间）从现有批次固定 100 篇：60 篇用于规则开发，40 篇保留到规则冻结后才核读、评测。标签由 **Codex 助手逐篇核读已存标题、完整摘要、MeSH 和出版类型**，记录为 `assistant_reviewed_provisional`，`human_reviewed=false`。这不是人工金标准；没有第二位独立标注者，保留集也不是盲法临床评估。当前不能据此训练或声称达到某种临床准确率。

| 抽样层 | 全批数量 | 开发集 | 保留集 |
| --- | ---: | ---: | ---: |
| v1→v2.1 从实体瘤转待判定 | 87 | 12 | 8 |
| 两版均待判定 | 201 | 18 | 12 |
| 其他范围分类变化 | 64 | 12 | 8 |
| 未变化的血液 / 混合范围 | 39 | 6 | 4 |
| 未变化的实体瘤范围 | 609 | 12 | 8 |
| 合计 | 1,000 | 60 | 40 |

因此覆盖原 288 篇待判定中的 **50 篇**，以及 151 篇分类变化中的 **40 篇**，两者重叠 20 篇；不是逐篇审核全部 288 篇。按固定 seed 的 SHA-256 排序抽样，关联 DOI、PMCID、规范化标题和 PubMed CommentsCorrections 链接形成组，每组只选一条，减少原文与通知跨集泄漏。这不能识别全部同研究衍生文章。抽样脚本、分组、原始版本 SHA-256 与输入哈希保存在评测目录。

样本来自近期发表日期排序的单批，且有意富集困难条目。**不按 1,000 篇或近五年全部文献的总体准确率解释样本分数。** 没有用保留集修订本轮规则；今后若据此修订，它就成为开发材料，需另设新保留集。

## 核读规范 `solid-tumor-annotation-v1`

范围与发表状态分别核读；本版不评估器官原发部位、组织学、研究类型、主题、人群这五个多标签轴。范围参考标签沿用路由枚举，但依据研究对象与用途核读，不抄录弱规则输出。

| 范围参考标签 | 核读准则 |
| --- | --- |
| `solid_candidate` | 已存材料明确实体癌种，或明确肿瘤实验采用有权威来源映射的实体瘤模型。包括预防、诊断、机制、治疗、生存者照护、风险及相关评论；不等于临床有效证据。原位癌相关研究保留在此范围。 |
| `hematologic_candidate` | 明确血液肿瘤为研究对象，单纯分子名称或仪器标准品不构成对象。 |
| `mixed_candidate` | 研究实质涉及实体及血液肿瘤，包括真实随访中报告的两类恶性结局；不凭偶然背景词判定。 |
| `solid_boundary_candidate` | 实质同时涉及实体癌与良性 / 癌前病变，如鉴别诊断、息肉与癌预防教育；正常对照细胞不构成此边界。 |
| `benign_candidate` | 明确良性病变为对象；正常细胞或泛称 benign diseases 不足以证明良性肿瘤。 |
| `precursor_candidate` | 息肉、癌前病变相关研究线索；不声称所有息肉都为癌前病变。仅提及癌的可能性、未确认癌病例组成时保守保留此类。 |
| `uncertain` | 已存信息不足以定位范围，或实为非肿瘤研究；保留记录，不自动删除。 |

`uncertain` 的参考理由另用 `relevance` 区分 `oncology_unspecified`（泛癌 / 未限定类型）、`non_neoplastic`（非肿瘤为主要对象）、`insufficient`（信息不足）。其他 relevance 为 solid、hematologic、mixed、solid_boundary、benign、precursor。边界不明确的条目保留 `needs_adjudication=true`，不能强制当作可靠训练标签。

发表状态以保存时的 PubMed 出版类型优先，标题标记作补充；撤稿通知与被撤稿原文分开，`unmarked` 只表示快照未见标记。核读未回查在线最新状态，不能证明论文未被撤稿。核读引用包含字段、原文短句及字符偏移；输入、版本、理由、标注者及时间均保留，未来人工复核应另存版本，不覆盖本轮结果。

HCT 116 与 JIMT-1 的模型映射分别核对 [Cellosaurus CVCL_0291](https://www.cellosaurus.org/CVCL_0291) 和 [CVCL_2077](https://www.cellosaurus.org/CVCL_2077)。仅增加这两项已核对别名，并要求标题 / 摘要存在肿瘤语境；不是通用细胞系识别器，仍需判断模型是研究对象还是校准材料。

## 本轮规则修订

新增 `solid-tumor-rules-v3`，旧 v1、v2、v2.1 词表和引擎行为保留。修订依据仅来自 60 篇开发集：

- 补充口咽癌、胃肠道癌及妇科癌表达，补充上述两种可追溯的实体瘤细胞模型。
- 排除 NBAS、MCL1 明确分子全名中的疾病词，防止非肿瘤研究被归为实体瘤、肺癌被归为实体 / 血液混合。
- 排除非恶性细胞、免疫细胞、组织背景及泛称 benign diseases 对良性病变标签的触发，保留真实良恶性比较。
- 被排除的命中仍保存原文位置和原因；继续搜索后面的真实疾病命中，避免一处分子名掩盖文中真实白血病。
- 待判定增加粗略分流提示，区分摘要不足、标题泛指肿瘤、缺乏具体范围信号；提示不自动确认非肿瘤或删除文章。

范围规则仍不能普遍理解否定、既往史、背景提及、研究入组条件与实际结果的关系。开发集中，息肉研究背景的癌提示和垂体癌患者既往腺瘤史仍会产生额外边界标签，已保留为待改进案例。

## 离线复评

```bash
DJANGO_DEBUG=1 DATABASE_PATH=/tmp/biomed-evaluation.sqlite3 \
  .venv/bin/python manage.py literature_evaluate \
  var/library/evaluations/solid-tumor-eval-v1/development-reviewed.json \
  var/library/evaluations/solid-tumor-eval-v1/holdout-reviewed.json \
  --manifest var/library/evaluations/solid-tumor-eval-v1/split-manifest.json \
  --taxonomy solid-tumor-rules-v2.1 --taxonomy solid-tumor-rules-v3
```

命令验证版本、分组、输入哈希、逐条引用偏移及完整分组，拒绝未核读样本、重复关联组或跳过困难条目。输出范围一致率、决定覆盖率（非待判定占比）、已决定样本一致率、已知参考范围一致率、逐类分母及混淆矩阵；无样本类别用空值，不报告虚假的满分。发表状态独立计分。可用 `--output <新文件>` 保存报告，不覆盖已有报告。

采集数据不会被评测命令修改。`development-inputs.json`、`holdout-inputs.json` 与 `split-manifest.json` 在规则修订前冻结；`rule-freeze.json` 记录打开保留集前的引擎、词表、标注规范与开发标签哈希。开发集用于定位错误，不能作为泛化分数。

### 发表状态补充核对

主评测集只有 2 条更正、98 条未标记，不能据此宣称撤稿检测准确。规则冻结后另行核对全部 **29 条已有发表状态提示**：7 条撤稿通知、19 条更正、3 条关注声明。按保存时的来源类型优先规范，两版与核读状态一致；这是一组富集的来源状态核对，和主评测重叠 2 条，不能合并分母，也没有被撤稿原论文类别样本。

发现两条标题 / 出版类型冲突需复核：

- PMID **42852634**：标题 `[Retracted]`，类型 `Retraction Notice`；现有规则已保存冲突，暂按撤稿通知。
- PMID **42875252**：标题 `Retraction notice to …`，类型 `Published Erratum`；按规范暂记更正。当前标题规则未覆盖这种写法，**未自动提示这一冲突**，已进入人工核对清单。不能据此把该文视作普通更正后直接用于训练。

本轮没有下载相关原文或回查最新发表状态。后续应核对来源关系及状态更新机制；当前临床证据发布流程未由此触发。
